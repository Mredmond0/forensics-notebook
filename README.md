# forensics-notebook
Мои заметки по темам цифровой криминалистике и реагированию на инциденты.
Здесь буду оставлять свои результаты по изучению той или иной теме для закрепления материала. 

#Мои цели на ближайший месяц:
1) Разобраться с основами работы в Linux для анализа.
2) Понять, как работает wireshark и изучить PCAP-файлы.
3) Выработать понимание, как хранятся данные на диске, а также что такое MFT, журналы, метаданные.
4) Изучить поподробнее в питоне чтение/запись файлов, работа с JSON/CSV, регулярные выражения (re), вызов команд системы (subprocess).
